# Pipe Nativo

The native iOS/Android app for **[Pipe](https://pipe.one)** — your self-hostable unified inbox + AI second brain. It connects to your own Pipe hub (the [open-source server](https://github.com/azweig/pipe)) and gives you a fast, native mobile experience: all your channels in one inbox, an AI layer that reads and drafts for you, and — optionally — **on-device AI** so correction and transcription run entirely on your phone.

> Built with Expo / React Native. Single-tenant, privacy-first: nothing is hardcoded — you point the app at your own hub at login.

## Features

- **5 tabs** — Mensajes (inbox), Calendario, Inicio (your day at a glance), Radar (what needs attention), Notas.
- **One inbox, every channel** — WhatsApp, email, Telegram, Signal, Slack and more, one thread per person.
- **AI that helps** — draft replies in your voice, summaries, "who needs a reply".
- **Voice notes** — record and send, or dictate → transcribe → send.
- **Text review before sending** — spelling/grammar polish with a clear "send as-is" option.
- **🧠 On-device AI (optional)** — install a ~550 MB local model pack (Qwen3-0.6B + Whisper base) to run **correction and transcription 100% on your phone**: offline, private, instant. Opt-in, removable, with automatic fallback to your hub. See **[SETUP-LOCALAI.md](SETUP-LOCALAI.md)**.
- **Alarms**, push notifications, and **ES / EN** localization.

## Stack

Expo `~57` · React Native `0.86` · React Navigation · `expo-audio` · `expo-file-system` · optional `llama.rn` + `whisper.rn` for on-device inference.

## Quick start

```bash
npm install
npx expo start          # dev (Expo Go for the JS-only parts)
```

At login, enter your **hub URL** (your Pipe server) and PIN. Nothing is stored server-side beyond your own hub.

### Native build (required for on-device AI)

`llama.rn` / `whisper.rn` are native modules → they don't run in Expo Go. Build a dev/EAS client:

```bash
npx expo install llama.rn whisper.rn
npx expo prebuild
eas build --profile development      # or: npx expo run:android | run:ios
```

Full walkthrough (iOS Metal, Android, model URLs, STT audio caveat): **[SETUP-LOCALAI.md](SETUP-LOCALAI.md)**.

## Configuration

- **Hub URL** — set at login (stored locally). No server is hardcoded.
- **Native dirs** (`android/`, `ios/`) are generated by `expo prebuild` (CNG) and git-ignored on purpose — regenerate them, don't commit them.
